# Contributing

Thanks for your interest in contributing! This project is meant to be simple and stay that way.

## What we'd love help with

- **Bug fixes** — if something breaks when you drop a file in, let us know or send a fix
- **Better styling** — improvements to the index page or the nav overlay
- **New Claude Code skills** — if you write a useful `/command` for prepping artifacts, share it
- **Documentation** — clearer instructions, screenshots, or translations

## How to contribute

1. Fork the repo
2. Create a branch (`git checkout -b my-fix`)
3. Make your changes
4. Test locally with `npm run dev`
5. Commit and push
6. Open a pull request

## Guidelines

- Keep it simple. This project is intentionally minimal.
- Don't add artifacts to your PR — they're gitignored for a reason.
- Test that `npm run build` passes before submitting.

## Questions?

Open an issue. No question is too basic.
