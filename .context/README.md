# Claude Artifacts Viewer

A local Next.js app for viewing JSX/TSX artifacts generated by Claude.

## Usage

1. Drop a `.tsx` file into `src/artifacts/` (e.g. `moving-calculator.tsx`)
2. Make sure the file has `"use client"` at the top and a `default export`
3. Run `npm run dev` and visit `http://localhost:3000`
4. Click the artifact from the index, or go directly to `/a/moving-calculator`

## File requirements

Each artifact file needs:
- `"use client"` directive at the top (since they use React hooks/interactivity)
- A default exported React component
- Filename becomes the URL slug (e.g. `my-app.tsx` → `/a/my-app`)

## Tailwind

Tailwind CSS is available out of the box. Artifacts can use any Tailwind classes.
